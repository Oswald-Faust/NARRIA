Bienvenue dans Narr'ia

NARR'IA détecte, quantifie et qualifie le vol d'intrigue dans les œuvres narratives. Le système extrait la structure narrative profonde d'un texte sous la forme d'un graphe, puis la confronte à d'autres œuvres pour repérer d'éventuelles correspondances structurales.

— Avertissement scientifique et éthique —

Les sorties de NARR'IA sont une aide à la décision, jamais un verdict. Aucun score, si élevé soit-il, ne constitue une preuve de plagiat. Les résultats sont probabilistes et doivent toujours être soumis à l'appréciation d'une expertise humaine qualifiée — narratologue, et le cas échéant juriste.

Configuration

Configuration

NARR'IA fonctionne en deux modes : local (heuristiques par mots-clés, rapide, gratuit, peu précis) ou LLM (analyse sémantique profonde via Claude, précis, payant, nécessite Internet).

Mode actif

Chargement…

Connecter votre clé API Anthropic (mode LLM)

Pour activer le mode d'analyse par Claude, fournissez votre clé API Anthropic personnelle. La clé est stockée uniquement sur votre machine, dans ~/.narria/config.json avec des permissions restrictives.

Pour obtenir une clé : créez un compte gratuit sur console.anthropic.com, puis créez une clé dans « API Keys ». Anthropic offre un crédit gratuit à la création du compte, suffisant pour analyser une vingtaine de textes courts.

Coût indicatif : modèle Claude Sonnet 4.5 à 3 USD par million de tokens d'entrée et 15 USD par million de tokens de sortie. Analyse d'un roman de 80 000 mots ≈ 0,50 USD.

Avertissements importants

  • Vie privée : en mode LLM, les textes que vous analysez transitent par les serveurs d'Anthropic. Pour des œuvres non publiées ou sensibles, vérifiez la compatibilité avec votre politique éditoriale. Anthropic n'entraîne pas ses modèles sur les données API par défaut.
  • Coût : chaque analyse LLM consomme des tokens facturés à votre compte Anthropic. L'application affiche une estimation de coût avant chaque analyse.
  • Fallback automatique : si aucune clé n'est configurée ou si l'API est indisponible, l'application bascule en mode local. Vos analyses continuent de fonctionner.
  • Confidentialité de la clé : ne partagez jamais votre clé API. Elle permet de débiter votre compte. Si vous partagez ce document ou cette application, supprimez la clé d'abord.
À propos

À propos de NARR'IA

NARR'IA est un système de narratologie computationnelle conçu pour la détection, la quantification et la qualification du vol d'intrigue — c'est-à-dire la reprise non déclarée et substantiellement identique de la structure narrative profonde d'une œuvre préexistante, indépendamment de la réalisation linguistique de surface.

Architecture

Le système s'articule en cinq modules interdépendants :

  • Module 1 — Segmentation narrative : découpage automatique du texte brut en unités narratives significatives.
  • Module 2 — Extraction de la structure : identification des fonctions cardinales, configurations actantielles, modalités et signature tensive. Production du graphe narratif (NarRep-Graph).
  • Module 3 — Analyse comparative : comparaison de deux graphes narratifs en cinq phases (ANN, isomorphisme, GED narrative, DTW, détecteurs typologiques). Production des scores SNS, SS, ST et SRJ.
  • Module 4 — Base de données : stockage et indexation des graphes narratifs dans un corpus de référence.
  • Module 5 — Interprétation et rapports : génération de rapports d'analyse nuancés, avec garde-fous contre les usages abusifs.

Principes éthiques

  • Les sorties de NARR'IA sont probabilistes, jamais définitives.
  • Les résultats doivent être interprétés par un expert humain.
  • Aucune accusation publique ne doit être formulée sur la seule base des sorties du système.
  • Les données traitées restent sur la machine de l'utilisateur ; rien n'est envoyé sur internet, sauf en mode LLM.
